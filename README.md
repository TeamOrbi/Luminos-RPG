# Luminos - The Multi User RPG, that's played over Email

Luminos is the First RPG (That we know about) that is played fully over email! Players start the game by emailing the server, then they get one game changing action a day. Explore the world, fight Monsters, go Shopping, and become powerful! Welcome... to Luminos!

## The Classes

While in the world of Luminos, you can pick from one of 8 classes. This **CANNOT** be changed, so choose wisely!

- **WARRIOR** - A sturdy fighter, that loves nothing more than a good fight!
- **MAGE** - A spellcaster, flinging impressive spells around.
- **ROGUE** - A sneaky and stealthy player, that loves nothing more than a good sneak attack.
- **PALADIN** - A holy and sacred knight, that fights for Justice
- **RANGER** - Attacking from behind, the Ranger loves to get a few shots in
- **CLERIC** - Healing and Helping, the Cleric has a high amount of health, and heals easily
- **WARLOCK** - The most powerful Magic user you will ever see, firing impressive spells at rate.
- **BARD** - The most musical of all, using some magical songs

## Setup

To Setup, you will need a MailGun account (They are free, up to 100 emails a day!)

First, clone the repo <br><br>
```bash
git clone https://github.com/TeamOrbi/Luminos-RPG
```

Then, enter the folder, and clone the env file, then edit it

```bash
cd Luminos-RPG
cp .env.example .env
nano .env
```
Replace the example values with your own

```
MAILGUN_DOMAIN: Your verified Mailgun sending Domain
MAILGUN_API_KEY:  Your private Mailgun API key
MAILGUN_BASE_URL: https://api.mailgun.net for US, https://api.eu.mailgun.net for EU
MAILGUN_FROM: A sender on the verified domain, Luminos RPG <playluminos@teamorbi.net> for example
INBOUND ADDRESS: The exact reciving address for commands, for example playluminos@teamorbi.net
MAILGUN_WEBHOOK_SIGNING_KEY: The Mailgun Webhook signing key, this is NOT the private API key
LUMINOS_TIMEZONE: The timezone that the server runs on, defaults to Adelaide/Australia
LUMINOS_DB_PATH: Unless modifying where Luminos stores its data, do not change this
PORT: Keep as 8000 unless you need to change the internal port.
```

Then, create a folder for the data to be saved to.

```bash
mkdir -p ./data
```
Then, verify config, and launch the server.
```bash
docker compose config
docker compose up -d --build
docker compose ps
```

To verify that it is working, check that the port is open

```bash 
curl http://127.0.0.1:8000/health
```
You should recive back
```aiignore
{"service":"luminos-email-rpg","status":"ok"}
```
We reccommend putting Luminos behind a Reverse Proxy, such as Caddy.
